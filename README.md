# veil-info.org

The front door for community built Veil tools. One static page linking everything:

- [VeilStreet](https://street.veil-info.org) live transaction visualizer and explorer, mainnet and [testnet](https://testnet-street.veil-info.org)
- [Mining Hub](https://mining.veil-info.org) copy paste mining commands and difficulty charts
- [Veil-Miner](https://github.com/Veil-Project/Veil-Miner/releases) GPU ProgPoW, [Veil-Miner-CPU](https://github.com/ohcee/Veil-Miner-CPU/releases) RandomX, and [Veil-Miner-SHA](https://github.com/ohcee/Veil-Miner-SHA/releases) GPU SHA256D
- [veil-node-stratum-proxy](https://github.com/ohcee/veil-node-stratum-proxy) solo mine all three algos straight to your own node
- [Academy](https://academy.veil-info.org) interactive lessons with a faucet that pays real VEIL
- [Chain snapshots](https://github.com/ohcee/veil-snapshots/releases) quarterly mainnet snapshots, SHA256 verified
- DNS seeder at seed.veil-info.org serving mainnet peer addresses

No build step, no dependencies, no web fonts, no analytics. One HTML file and the Veil mark. The page makes zero third party requests.

Served with GitHub Pages at [hub.veil-info.org](https://hub.veil-info.org) for now, moving to the veil-info.org root later.
